# Cartes

## Que signifie HTTP ?
> **HyperText Transfer Protocol**. C'est le protocole de communication utilisé pour transférer des ressources (pages, images, données) entre un client et un serveur web.

## Quelle est la différence entre GET et POST ?
> **GET** récupère une ressource et passe ses paramètres dans l'URL. Il ne doit pas modifier l'état du serveur.
> **POST** envoie des données dans le corps de la requête et peut créer ou modifier une ressource.

## À quoi sert le DNS ?
> Le **Domain Name System** traduit un nom de domaine lisible (ex. `cgkensan.dbwe.tech`) en adresse IP utilisable par les machines.

## Qu'est-ce qu'une API REST ?
### Verso
> Une API REST expose des ressources identifiées par des URL et utilise les méthodes HTTP (`GET`, `POST`, `PUT`, `DELETE`) pour les manipuler. Elle est sans état : chaque requête contient les informations nécessaires.

## Que signifie HTML ?
> **HyperText Markup Language**. C'est le langage de balisage qui structure le contenu d'une page web.

## Quel est le rôle de CSS ?
> CSS (**Cascading Style Sheets**) décrit la présentation d'un document HTML : couleurs, typographie, espacements, mise en page et responsive design.
